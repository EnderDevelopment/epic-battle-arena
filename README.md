# Roblox Battle Grounds

This project contains scripts for a Roblox battle grounds experience, featuring player management, game state handling, weapon systems, shared utilities, player controls, and UI updates. The scripts are designed to create an engaging and competitive battle environment within Roblox.

## Install

1. Download the `BattleGrounds.zip` file from the project repository.
2. Extract the contents of the zip file.
3. Open Roblox Studio.
4. Create a new Roblox experience or open an existing one.
5. Place the scripts in the following locations:
   - `ServerScriptService/BattleGrounds/PlayerManager.server.lua`
   - `ServerScriptService/BattleGrounds/GameManager.server.lua`
   - `ServerScriptService/BattleGrounds/WeaponManager.server.lua`
   - `ReplicatedStorage/BattleGrounds/SharedUtils.lua`
   - `StarterPlayerScripts/BattleGrounds/PlayerUI.client.lua`
   - `StarterPlayerScripts/BattleGrounds/PlayerControls.client.lua`

## Use

1. Start the Roblox experience in Roblox Studio.
2. Test the battle grounds experience by playing as multiple players.
3. Monitor the game state, player attributes, and UI updates to ensure everything is working correctly.
